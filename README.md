# DayFlow HRM Frontend

DayFlow is a modern, high-performance Human Resource Management System built with Next.js 14 (App Router), TypeScript, and Tailwind CSS.

## Features

- 🔐 **Authentication**: Role-based access control (Admin vs. Employee).
- 👔 **Employee Portal**:
  - Personal Dashboard with live Clock In / Clock Out timer.
  - Profile Management.
  - Attendance history log & stats.
  - Leave Applications & balance tracking.
  - Payroll breakdown & downloadable payslips.
- 👑 **Admin Portal**:
  - Company overview dashboard (headcount, attendance rate, pending approvals, payroll budget).
  - Employee Management (Directory, Add/Edit employee, status toggle).
  - Attendance Tracker & company-wide status overrides.
  - Leave Approvals workflow (Approve/Reject requests).
  - Payroll Processing & automated payslip generation.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
